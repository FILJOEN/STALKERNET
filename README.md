# STALKERNET
It's my very 1st mod. it's just a fan made mod. 
This mod is built by the help of Chatgpt and Claude. 
It's just a python script that shows an image of a small digital device. The script adds random text and gifs with glitch effects, typewriter effects, fonts, and the image will move up and down automatically when it detects the game's mouse cursor so it hides itself in game menus/loot menus/trader menus, the pda etc.
It does not read or modify any game data or files. It's purely a cosmetic overlay to show random messages and gifs. All can be found in the folders of the mod.
Claude created the build_exe.bat for me to run next to stalkernet.py and it created the Stalkernet.exe and a launch_stalker2_with_overlay.bat to run the exe/script when Stalker 2 is run from Steam, it will also stop the script when Stalker is closed.
Source code for the STALKERNET cosmetic PDA-style overlay for S.T.A.L.K.E.R. 2 can be found in the repositories.
